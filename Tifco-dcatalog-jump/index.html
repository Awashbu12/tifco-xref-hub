Offline-ready PWA. Search runs on a local JSON index built from your catalog PDF. Links open DCatalog with ?page= (works on most DCatalog viewers).
How this works
  1. Put the full catalog PDF in this folder as catalog.pdf.
  2. Run python build_index.py to generate catalog_search_index.json.
  3. Host this folder (GitHub Pages) and search away.
Why: your daily app search is… not good. This gives you a “Ctrl+F across the whole catalog” experience and jumps you to the interactive catalog page.
